00 · Orientation

今天先理解“为何能检索”，再讨论“如何训练”

Embedding 不是把一段文本压缩成一串数字这么简单。它是一个可被检索系统使用的表示契约：相同语义应更接近、可独立编码的向量应能被高效索引、而最终精确判断仍可能需要更丰富的交互。

01 · Independent encoding

双塔的关键不是“两套模型”，而是 query 与 document 能否独立完成编码

先不背任何训练公式。只把注意力放在一个工程问题：在线请求到来之前，哪些计算已经可以做完；而哪些计算必须等 query 出现才有意义。

场景

企业知识库有 100 万个 chunk，用户查询到返回 top-k 的预算约 100ms。你可以提前处理文档库，但无法提前知道用户下一次会问什么。
