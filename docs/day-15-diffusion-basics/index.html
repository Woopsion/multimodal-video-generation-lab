2. Step 01：前向加噪到底做了什么

从数据集中取一张干净图片，记作 x₀。前向扩散会根据时间步 t，保留一部分原始信号，同时混入一部分高斯噪声，得到 xₜ。

2.1 为什么要人为加噪

直接学习“随机噪声一步变成完整图片”跨度太大。扩散模型先把真实图片逐渐连接到一个简单、可采样的噪声分布，再让网络学习许多个较小的反向去噪问题。

困难的一步生成：random noise -> complete image

扩散模型的拆分：
random noise -> 稍微去噪 -> 再稍微去噪 -> ... -> image
前向加噪的目的：不是增强图片，也不是永久破坏数据，而是自动制造不同难度的训练样本，并为每个样本保留一份已知的噪声答案。

现代方法来源：2015 年 Sohl-Dickstein 等人的 Deep Unsupervised Learning using Nonequilibrium Thermodynamics 建立了现代扩散概率模型的重要路线。

2020 年 Ho 等人的 Denoising Diffusion Probabilistic Models，即 DDPM，把训练目标简化为实用的噪声预测形式并推动了后续图像生成。

2.2 正态分布与高斯噪声

正态分布也叫高斯分布。它描述一种连续随机变量：数值大多集中在均值附近，离均值越远，出现概率通常越低，整体形状像一口对称的钟。

f(x) = 1 / (σ√2π) · exp( -(x-μ)² / (2σ²) )
μ：均值钟形曲线的中心，决定数据整体位于哪里。
σ²：方差表示数值围绕均值的离散程度。
σ：标准差方差的平方根，单位与原始数据相同。
N(0,1)均值为 0、方差为 1 的标准正态分布。

对于标准正态分布，大约 68% 的值位于 [-1,1]，95% 位于 [-2,2]，99.7% 位于 [-3,3]。因此采样结果大多接近 0，偶尔出现绝对值较大的数。

为什么经典图像扩散偏爱高斯噪声：多个独立高斯变量的线性组合仍然是高斯分布，分布形式容易计算；它能平滑地扰动连续像素；最终可以把数据分布连接到简单的 N(0,I)，生成时很容易采样。

高斯噪声不是唯一选择。离散扩散、掩码扩散和其他生成方法可以使用类别替换、mask 或不同破坏过程；经典 DDPM 选择高斯噪声主要是因为连续图像场景下数学和工程都很方便。

2.3 ε 到底是什么

ε 不是一个神秘常数，也不是最终 loss。它是本次训练临时采样出来的一整个噪声张量，并且形状与图片张量相同。

干净图片x₀.shape = [C,H,W]

每个位置保存归一化后的像素值。

噪声答案ε.shape = [C,H,W]

每个位置独立采样一个近似 N(0,1) 的数。

带噪输入xₜ.shape = [C,H,W]

原图信号与 ε 按时间步系数混合。

某几个 ε 元素可能是：
[ 0.12, -0.35, 0.03, 1.24, -0.71, ... ]

它不是视觉上的固定白点图案，
而是覆盖所有通道与空间位置的随机数张量。
符号含义现在需要怎样理解
x₀干净的真实样本训练数据中的原始图片。
t扩散时间步表示当前破坏程度，不是现实世界的秒数。
ε高斯噪声通常从标准正态分布采样，模型训练时会尝试预测它。
ᾱₜ累计信号保留比例时间步越大，它通常越小。
xₜ第 t 步的带噪样本由原图信号和随机噪声共同组成。

2.4 拖动时间步观察信号如何消失

几乎完整的原始信号 此时 xₜ 接近 x₀，图像结构清晰。
信号系数 √ᾱₜ1.000
噪声系数 √(1-ᾱₜ)0.000

2.5 核心公式：原图与噪声怎样混合

xₜ = √ᾱₜ · x₀ + √(1-ᾱₜ) · ε

第一项是保留下来的原图信号，第二项是加入的随机噪声。时间步增加时，一般表现为信号系数下降、噪声系数上升。

前向过程不学习

噪声分布和 schedule 由我们定义。它不需要神经网络，也没有需要优化的参数。

随机性来自 ε

同一张图片、同一个时间步，如果重新采样噪声，也可以得到不同的 xₜ。

2.6 训练时不必真的循环加噪 t 次

由于高斯噪声具有良好的组合性质，我们可以使用上面的闭式公式，从 x₀ 直接采样任意时间步的 xₜ。

# 教学伪代码
x0 = sample_real_image()
t = sample_random_timestep()
epsilon = sample_gaussian_noise()

xt = sqrt(alpha_bar[t]) * x0 \
   + sqrt(1 - alpha_bar[t]) * epsilon
常见误解：训练时并不是每取一张图片都从第 1 步循环加噪到第 t 步。可以随机选择一个 t，然后直接构造对应的 xₜ。
为什么要这样做：模型会在训练中看到各种噪声程度，从接近原图到接近纯噪声，为后面学习完整反向过程准备样本。

3. Step 02：训练时为什么预测噪声

前向过程解决了训练样本怎么制造。现在模型真正开始学习：给它带噪图片 xₜ 和时间步 t，要求它预测当初加入的噪声 ε。

x₀真实图片
t随机时间步
ε随机噪声答案
xₜ构造带噪输入
εθ(xₜ,t)网络预测噪声
MSE loss预测与真实 ε 比较

3.1 模型的输入与输出

角色张量作用
输入 1xₜ当前噪声程度下的图片。
输入 2t告诉网络当前处于哪个噪声等级，通常会转换成 timestep embedding。
模型输出ε̂ = εθ(xₜ,t)网络认为图片中包含的噪声张量。
监督答案ε构造 xₜ 时实际采样并加入的噪声。

3.2 loss 如何计算

L = E[ || ε - εθ(xₜ,t) ||² ]

这是均方误差的写法：逐个位置比较真实噪声 ε 与预测噪声 ε̂，把差值平方后求平均。反向传播会调整网络参数 θ，让预测越来越接近真实噪声。

# 一次训练迭代的核心逻辑
x0 = sample_real_image()
t = sample_random_timestep()
epsilon = randn_like(x0)
xt = add_noise(x0, epsilon, t)

epsilon_pred = model(xt, t)
loss = mse(epsilon_pred, epsilon)

loss.backward()
optimizer.step()

3.3 为什么预测 ε，而不是直接输出一张干净图片

答案天然已知

ε 是训练程序自己采样的，因此不需要人工标注就能得到精确监督目标。

目标分布统一

不同图片、不同时间步的噪声都来自标准正态分布，网络面对的目标尺度更稳定。

等价于寻找去噪方向

如果知道当前样本中哪些成分属于噪声，就能结合 scheduler 估计更干净的状态。

不是唯一参数化

其他扩散模型也可能预测 x₀、score 或 v；预测 ε 是经典 DDPM 的常用选择。

不要直接理解成 xₜ - ε̂：真实反向一步还要使用时间步对应的系数和 scheduler 公式，把噪声预测转换成对 xₜ₋₁ 或 x₀ 的估计。这个细节属于 Step 03。
当前核心：网络不是在背某张训练图片，而是在大量图片、随机时间步和随机噪声上，学习“给定当前噪声状态，哪一部分更像噪声”。

4. Step 03：DDPM 与反向去噪

4.1 DDPM 全称是什么

DDPM 的全称是 Denoising Diffusion Probabilistic Models，中文通常译为“去噪扩散概率模型”。它来自 Ho、Jain、Abbeel 在 2020 年发表的同名论文。

单词含义对应过程
Denoising去噪神经网络学习从高噪声状态恢复到更干净状态。
Diffusion扩散前向过程逐步加入高斯噪声，让数据结构逐渐消失。
Probabilistic概率式每一步都描述为条件概率分布，而不是唯一确定的像素变换。
Models模型使用参数为 θ 的神经网络近似未知的反向分布。
DDPM 不是网络结构名称：经典实现可以使用 UNet，但 DDPM 本身描述的是前向概率过程、训练目标和反向采样方法的整体框架。

4.2 DDPM 的三条完整流程

前向过程：固定，不训练

x₀真实图片
x₁少量噪声
x₂更多噪声
...Markov chain
xT近似 N(0,I)
q已知分布
q(xₜ | xₜ₋₁) = N( √αₜ · xₜ₋₁, βₜ I )
  • βₜ：第 t 步加入多少噪声，由 noise schedule 预先设定。
  • αₜ = 1 - βₜ：第 t 步保留多少原状态。
  • ᾱₜ = α₁α₂...αₜ：从第 1 步累计到第 t 步的信号保留量。
  • I：单位矩阵，表示各维度使用同尺度、相互独立的高斯噪声。

这是一条 Markov chain：前向第 t 步只依赖 xₜ₋₁。但由于高斯分布可组合，训练时又能通过 ᾱₜ 从 x₀ 直接采样 xₜ。

训练过程：随机抽一个时间步学习预测 ε

x₀ -> sample t and ε -> construct xₜ
xₜ + t -> neural network -> ε̂
loss = MSE(ε̂, ε)
backward -> update θ

训练不会为每张图片完整执行 T 次反向链。每次随机抽取一个 t，让网络学习该噪声等级下的预测任务。大量训练后，网络覆盖从轻噪声到重噪声的不同状态。

采样过程：从纯噪声顺序执行所有反向步骤

xT随机高斯噪声
ε̂T模型预测
xT-1稍微更干净
...反复调用模型
ε̂1最后预测
x₀生成图片

4.3 一次反向更新到底做什么

DDPM 假设反向一步也是高斯分布，并用神经网络参数化其均值：

pθ(xₜ₋₁ | xₜ) = N( μθ(xₜ,t), σₜ² I )

经典噪声预测参数化下，scheduler 使用网络预测的 ε̂ = εθ(xₜ,t) 计算反向均值：

μθ = 1/√αₜ · ( xₜ - βₜ/√(1-ᾱₜ) · ε̂ )

然后从这个反向分布中采样：

xₜ₋₁ = μθ(xₜ,t) + σₜ z,　z ~ N(0,I)
  • 第一部分 μθ：根据预测噪声计算“更干净状态应该位于哪里”。
  • 第二部分 σₜz：保留反向过程的随机性，使生成结果不是唯一的。
  • 到最后一步通常不再额外加入随机噪声，得到最终样本。
scheduler 的职责：保存 βₜ、αₜ、ᾱₜ、σₜ 和采样时间步，并把网络输出 ε̂ 转换成真正的 xₜ₋₁。神经网络负责预测，scheduler 负责按数学规则更新样本。

4.4 为什么反向过程还要有随机项

一张高噪声图片可能对应很多合理的更干净状态。DDPM 不把反向过程看成唯一答案，而是建模为条件概率分布。随机项让同一个初始条件可以产生不同但合理的样本。

训练与推理的关键差异：训练时可以随机抽一个 t 独立学习；推理时必须从 xT 开始，按照 scheduler 的时间步顺序反复预测和更新，直到得到 x₀。
