Week 2 - Multimodal Understanding

从图片 patch 到图文向量对齐

Week1 已经建立了训练、推理、Transformer 和 LLM 的基础。Week2 开始进入多模态理解：先看 ViT 如何把图片变成 token，再看 CLIP 如何把图片和文本放进同一个向量空间。

0. 本周目标

Week2 的目标是理解多模态理解模型的入口：图片如何变成 patch token，图片向量和文本向量如何对齐，为什么 CLIP 可以做零样本分类和图文检索。

本周主线：图片像素 -> patch embedding -> ViT image embedding；文本 token -> text embedding；CLIP 用对比学习把二者拉到同一个语义空间。

要打印

图片、patch、patch embedding、position embedding 的 shape。
